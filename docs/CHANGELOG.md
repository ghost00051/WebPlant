# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — SemVer.

## [1.4.1] — 2026-10-27

Патч по итогам аудита пользовательских сценариев 1.4.0: исправлены регрессии уведомлений, «мёртвые» кнопки, скрытая публикация сада, перенос растений и гостевых данных, health-check и ошибки интерфейса.

### Fixed — уведомления

* Дайджест учитывает настройки растения: `notify_morning`, `reminder_weekdays` (по часовому поясу) и приостановленные напоминания; «за день» больше не теряется — в утреннюю сводку добавлена строка «Завтра полить» для растений с `notify_day_before`.
* «Утренняя сводка» реально выключается: `delivery_mode` и `morning_summary_enabled` синхронизируются, сводка идёт только в digest, индивидуальные push — только в per_plant (убраны двойные уведомления в 09:00).
* Пустая сводка («полив не запланирован») больше не пушится каждый день.
* Тихие часы не отменяют push на слот, а откладывают его до окончания окна (доставка ровно один раз, без потери и дублей).
* `PATCH /api/users/me/notification-preferences`: невалидные тихие часы (`start == end`) теперь отклоняются до записи в БД; ошибки 400/422 больше не выдаются за «сервер не обновлён», при локальном сохранении UI честно помечает настройки как не применённые на сервере.

### Fixed — растения, фото, health-check

* Новый `POST /api/plants/{id}/health-check`: проверка по фото идёт одним запросом (без гарантированного 404 и повторной загрузки фото), результат сохраняется в аккаунте (`plant.metadata.health_check` и `metadata.diagnosis` фото) и доступен на других устройствах; битое фото — 400, недоступность ИИ — 503.
* Удаление фото не ломает файл, если на него ссылаются другие записи; галерея ограничена 200 фото; лимит загрузок поднят до 30/час.
* `watering_state` согласован с календарём: просроченное растение получает `status='missed'` и `overdue`, окно grace вынесено в `grace_hours`.
* Подбор вида по фото: нечитаемое изображение — 400 вместо 503.
* Серия ухода: API отдаёт `available/canFreeze/used/frozenDates/daysLeft` и `breakReason`; UI больше не предлагает мёртвую кнопку «Заморозить», а объясняет авто-прощение первого пропуска в неделю.
* Weekly recap считает серию в часовом поясе пользователя; уведомление «Ваш сад посмотрели» не учитывает просмотры владельца, дедуплицирует визиты и не сдвигает троттлинг при ошибке.

### Fixed — фронтенд

* «Поделиться» на карточке растения больше не публикует весь сад молча: явное подтверждение, ошибка вместо ссылки на личный кабинет, отмена шаринга — нейтральный статус.
* Перенос «до трёх растений» из публичного сада реально работает: мультивыбор предзаполняется, несовпавшие растения можно добавить из блока «Из общего сада», после успеха данные очищаются.
* Гостевая переписка очищается и объявляется перенесённой только после подтверждения серверной линковки (`guestLink` в ответах регистрации/входа); старый бэкенд не приводит к потере локальной копии.
* Онбординг: пресет «Сколько растений» влияет на сценарий добавления, «Пропустить» уводит на главную; диалог health-check корректно отменяется и не «оживает» после закрытия; частичный сбой мультивыбора показывает, какие растения не добавлены.
* Ошибки действий ухода больше не переводят всю главную в состояние ошибки; профиль и гостевой чат получили честные состояния ошибок/повторов; калькулятор — корректные «2–3 дня» и проценты.
* Инфраструктура/SEO: share-токен с TTL 7 дней, `/garden` без canonical на 404-URL, catch-all отдаёт NotFound с noindex, публичные страницы не запрашивают настройки уведомлений у гостя.

### Notes

* Миграций БД не добавлено; изменения API аддитивны (старые поля сохранены).
* Остаются известные низкоприоритетные ограничения из прошлого аудита: автозум на ландшафтных телефонах (>768px), отсутствие focus-trap в AI-диалогах, офлайн-отметка пропуска без оптимистичного удаления карточки, контракт `REMINDER_MISSED_POLICY=preserve` (только `missed_since` слот).

## [1.4.0] — 2026-10-27

Релиз по роадмапу продукта (48 фич из `Lejka_features_roadmap.xlsx`) + SEO-программа + устранение «дёрганья» интерфейса.

* Лендинг: гостевой чат «Спросите о своих растениях» без регистрации с переносом истории в аккаунт (F01), интерактивный демо-сад с «Полить» (F02), живой сценарий «Сегодня полить нечего» (F03), блок продуктовых фактов (F04).
* Регистрация/вход: онбординг-вопрос «Сколько у вас растений?» (F08), перенос гостевого чата/диагнозов при регистрации (F09), мягкое маркетинговое согласие (F10).
* Главная: одна кнопка «Полить» в сводке дня (F12), блок «Первый день» о новом растении (F13), объяснимые пропуски с «Полил(а) позже» (F14), сводка «На неделю» (F15), заморозка серии и разбор её обрыва (F16, UI), табы «Полив/Уход» (F17), бейдж «Что нового» и инсайт дня (F18), сезонный бейдж (F19), единый список задач растения (F32).
* Добавление растения: шаг 2 без ИИ-переписки — интервал подставляется автоматически + «Поправить» (F21), «Комната» и «Свет» (F22), «Я только что полил» (F23), мультивыбор растений (F24), подбор вида по фото (F25, после выкладки API).
* Мои растения: «Полить» на карточке (F26), пустое состояние с подборкой (F27), комната/свет в редактировании (F28), «Проверить здоровье» в один тап (F29), снимки роста «до/после» (F30), «Поделиться растением» (F31), последняя проверка здоровья (F34), кнопка «Добавить ещё растение» (шапка + нижний CTA).
* Чат с ИИ: явная «Диагностика по фото» (F35), персональные стартовые подсказки (F36), несколько фото в сообщении (F37), устойчивый фолбэк ошибок с «Повторить» (F38), «Применить совет» (F39).
* Уведомления: группировка по растениям + «Полил» в строке (F40), дайджест по умолчанию (F41), настройки каналов в шапке (F42), «тихие часы» (F43).
* Профиль и публичный сад: «Напоминания» наверх профиля (F44), «Поделиться садом» с цифрами (F45), «Достижения» (F46), CTA «Создать свой сад» с переносом растений (F48), «Хочу такое же» (F49), уведомление владельцу о просмотрах (F50, UI).
* Гайды: CTA «Следить за этим растением» (F05), калькулятор «когда поливать» без регистрации (F06), «Проверить по фото» в статье о жёлтых листьях (F07).

### Added — backend/API (аддитивно, обратная совместимость)

* `watering_state` и объяснимые пропуски полива в `/api/plants` и `/api/plants/schedule`, политика `REMINDER_MISSED_POLICY=preserve` (F14).
* Заморозка серии в `/api/users/me/care-streak` (F16).
* Настройки уведомлений: режим доставки (дайджест) и тихие часы, применение в reminder-джобе (F41/F43).
* Галерея фото роста: таблица `plant_photos`, POST/GET/DELETE с миниатюрами (F30).
* Уведомление «Ваш сад посмотрели N раз» с троттлингом (F50).
* Подсказка вида по фото `POST /api/plants/suggest-species-photo` (F25).
* Перенос гостевых чатов/диагнозов/согласий при регистрации и входе (F09).
* Миграции `20261105`, `20261106`, `20261107`; контракт в `docs/api/openapi.yaml`.

### Changed — SEO и производительность

* Уникальные title/description под интенты для всех 24 indexable URL, `SECTION_META` как единый источник.
* JSON-LD: `WebSite`, `Organization` (+logo), `FAQPage` хаба `/care`, `datePublished` у статей.
* sitemap: `lastmod` из реальных дат контента; `DirectorySlash Off` — `/plants` отдаёт 200 без редиректа; единая кастомная 404.
* Футер связал все 10 растений и 11 статей; хаб `/care` расширен (FAQ, 4 h2, 653 слова).
* `.htaccess`/эталонный nginx: `immutable` для `/assets/`, brotli, clean URLs; `robots.txt` — `Clean-param`, `/admin`.
* Новые гейты: `scripts/seo-check.mjs` (dist), `scripts/seo-audit.mjs` (прод), `verify:ui` (стабильность UI в headless Chrome).

### Fixed — UI-стабильность

* SPA-навигация больше не открывает новый маршрут с прежней прокруткой: `ScrollManager` в `App.jsx` (PUSH/REPLACE → начало страницы, POP → восстановление, sessionStorage переживает F5, поддержка внутренних скролл-контейнеров), `history.scrollRestoration='manual'`.
* Подтверждено отсутствие сдвигов от баннеров, скелетонов, FOUT шрифта, SW-обновления и гидратации пререндера (CLS ≤ 0.0156 на всех проверенных маршрутах, 0 исключений React).

### Tests

* Frontend: 259 unit-тестов (было 140), backend: 707 тестов (691 pass, 16 интеграционных skip без БД); axe: 0 нарушений на ключевых маршрутах; headless-сценарии 390×844 и 1440×900, light/dark.

* F11 (вход без пароля через Telegram/MAX) — P2, отложено.
